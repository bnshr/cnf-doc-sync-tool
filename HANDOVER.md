## 1. What This Tool Does

This tool synchronizes documentation changes from a **private** Verizon CNF best practices repo to a **public** Red Hat Kubernetes best practices repo. It uses AI to classify each change as Verizon-specific (keep private) or generic (safe for public), then provides a web-based review UI for human accept/reject decisions and automated PR creation.

**Repos involved:**

| Repo | Role | File prefix | Example |
|------|------|-------------|---------|
| `vz-cnf-best-practices-guide` | Private (source) | `cnf-best-practices-*` | `cnf-best-practices-helm.adoc` |
| `guide` | Public (target) | `k8s-best-practices-*` | `k8s-best-practices-helm.adoc` |

**Verizon-specific markers** the tool detects:
- `.VCP CNF requirement`, `.VCP CNF recommendation`
- `Doors Id`, `Requirement Id` (VZ requirement tracking IDs)
- `Verizon`, `VCP`, `Webscale`, `WebScale`
- `ENSE` (VZ network fabric), `SPK` (VZ load balancer)
- Internal hostnames, approval processes, hardware specs
- Files matching `*-vz-*` pattern (auto-classified, no AI needed)

## 6. JSON Data Format (the integration contract)

This is the format any classification engine must produce. The Review UI and PR publisher consume it.

```json
{
  "version": 1,
  "created_at": "2026-06-11T00:00:00Z",
  "private_repo": "/path/to/vz-cnf-best-practices-guide",
  "public_repo": "/path/to/guide",
  "since_ref": "abc1234",
  "head_ref": "def5678",
  "public_ref": "ghi9012",
  "files": [
    {
      "id": "f1",
      "private_path": "modules/cnf-best-practices-helm.adoc",
      "public_path": "modules/k8s-best-practices-helm.adoc",
      "file_classification": "shared",
      "file_classification_reason": "Has public counterpart",
      "private_content_before": "...",
      "private_content_after": "...",
      "proposed_public_content": "...(VZ markers stripped)...",
      "final_content": "",
      "decision": "pending",
      "reviewer_classification": "",
      "hunks": [
        {
          "id": "f1-h1",
          "hunk_header": "@@ -1,5 +1,7 @@",
          "diff_text": "...",
          "classification": "generic",
          "reason": "Cloud-native best practice, no VZ markers",
          "vz_references": [],
          "generic_summary": "Updated Helm v3 guidance",
          "vz_summary": ""
        }
      ]
    }
  ]
}
```

**Key fields:**
- `file_classification`: `"vz_specific"` | `"shared"` | `"ambiguous"`
- `decision`: `"pending"` | `"accepted"` | `"rejected"` | `"auto_excluded"`
- `hunks[].classification`: `"generic"` | `"verizon-specific"` | `"mixed"`

Any tool that produces this JSON can drive the Review UI via:
```bash
python -m cnf_doc_sync_ui --data <path-to-json>
```

Add a standalone Python CLI script (`classify.py`) that replaces the Claude Code skill. The Review UI and PR publisher remain unchanged.

### classify.py Design

```python
#!/usr/bin/env python3
"""
Standalone CNF doc sync classifier.
Replaces the Claude Code skill with local/cloud LLM support.
"""
import argparse, asyncio, json, subprocess, re, httpx
from datetime import datetime
from pathlib import Path

# --- LLM Providers ---

class OllamaProvider:
    def __init__(self, model="qwen2.5:7b", url="http://localhost:11434"):
        self.model = model
        self.url = url

    async def classify(self, prompt: str) -> str:
        async with httpx.AsyncClient(timeout=300) as client:
            r = await client.post(f"{self.url}/api/generate", json={
                "model": self.model, "prompt": prompt, "stream": False
            })
            r.raise_for_status()
            return r.json()["response"]

class OpenAIProvider:
    def __init__(self, model="gpt-4o", api_key=None):
        self.model = model
        self.api_key = api_key or os.environ["OPENAI_API_KEY"]

    async def classify(self, prompt: str) -> str:
        async with httpx.AsyncClient(timeout=120) as client:
            r = await client.post("https://api.openai.com/v1/chat/completions",
                headers={"Authorization": f"Bearer {self.api_key}"},
                json={"model": self.model,
                      "messages": [{"role": "user", "content": prompt}]})
            r.raise_for_status()
            return r.json()["choices"][0]["message"]["content"]

class AnthropicProvider:
    def __init__(self, model="claude-sonnet-4-6", api_key=None):
        self.model = model
        self.api_key = api_key or os.environ["ANTHROPIC_API_KEY"]

    async def classify(self, prompt: str) -> str:
        async with httpx.AsyncClient(timeout=120) as client:
            r = await client.post("https://api.anthropic.com/v1/messages",
                headers={"x-api-key": self.api_key,
                         "anthropic-version": "2023-06-01"},
                json={"model": self.model, "max_tokens": 4096,
                      "messages": [{"role": "user", "content": prompt}]})
            r.raise_for_status()
            return r.json()["content"][0]["text"]

PROVIDERS = {
    "ollama": OllamaProvider,
    "openai": OpenAIProvider,
    "anthropic": AnthropicProvider,
}

# --- Git Operations ---

def git(repo, *args):
    r = subprocess.run(["git", "-C", repo] + list(args),
                       capture_output=True, text=True)
    return r.stdout.strip()

def get_changed_files(repo, commit):
    return git(repo, "diff", f"{commit}^..{commit}", "--name-status")

def get_diff(repo, commit, filepath=None):
    cmd = ["diff", f"{commit}^..{commit}"]
    if filepath:
        cmd += ["--", filepath]
    return git(repo, *cmd)

def get_file_at(repo, commit, filepath):
    return git(repo, "show", f"{commit}:{filepath}")

# --- Classification ---

VZ_PATTERN = re.compile(
    r'(\.VCP CNF|Doors Id|Requirement Id|Verizon|VCP\b|Webscale|WebScale|'
    r'\bENSE\b|\bSPK\b|CPI 810)', re.IGNORECASE
)

CLASSIFICATION_PROMPT = """You are analyzing a diff from a private Verizon CNF
documentation repo to determine if the content is safe to sync to a public
Red Hat Kubernetes best practices repo.

**File:** `{filename}`

**Diff hunks:**
```diff
{diff}
```

**Verizon-Specific Markers — classify as VZ-specific if ANY appear:**
- "Verizon", "VCP", "Verizon Communications"
- "Doors Id" or "Requirement Id" (Verizon tracking IDs)
- ".VCP CNF requirement" or ".VCP CNF recommendation"
- "ENSE", "SPK", "Webscale", "WebScale"
- Internal hostnames, URLs, hardware specs
- "CPI 810" or similar internal standards

**For EACH hunk, respond with JSON:**
```json
[{{"hunk_number": 1, "classification": "generic|verizon-specific|mixed",
   "reason": "...", "vz_references": [...],
   "generic_summary": "...", "vz_summary": "..."}}]
```"""

async def classify_file(provider, filename, diff_text):
    """Classify a single file's diff hunks."""
    # Layer 1: Auto-skip VZ-prefixed files
    if "-vz-" in filename:
        return {"classification": "vz_specific", "reason": "VZ-prefixed file"}

    # Layer 2: Check if ALL diff lines contain VZ markers
    changed_lines = [l for l in diff_text.split("\n")
                     if l.startswith(("+", "-"))
                     and not l.startswith(("+++", "---"))]
    if changed_lines:
        vz_count = sum(1 for l in changed_lines if VZ_PATTERN.search(l))
        if vz_count == len(changed_lines):
            return {"classification": "verizon-specific",
                    "reason": "All changed lines contain VZ markers (regex)"}

    # Layer 3: LLM classification for ambiguous cases
    prompt = CLASSIFICATION_PROMPT.format(filename=filename, diff=diff_text)
    response = await provider.classify(prompt)

    # Parse JSON from LLM response
    try:
        # Strip markdown fences if present
        text = response.strip()
        if "```" in text:
            text = text.split("```")[1]
            if text.startswith("json"):
                text = text[4:]
        return json.loads(text)
    except (json.JSONDecodeError, IndexError):
        return {"classification": "mixed",
                "reason": "LLM response unparseable — defaulting to mixed"}

# --- Main Pipeline ---

async def run(args):
    provider = PROVIDERS[args.provider](
        model=args.model,
        **({"url": args.ollama_url} if args.provider == "ollama" else {})
    )

    private_repo = args.private_repo
    public_repo = args.public_repo
    commit = args.private_commit

    # Get changed files
    name_status = get_changed_files(private_repo, commit)
    files_data = []

    for line in name_status.strip().split("\n"):
        if not line.strip():
            continue
        parts = line.split("\t")
        status, filepath = parts[0], parts[-1]
        if not filepath.startswith("modules/"):
            continue

        topic = filepath.replace("modules/cnf-best-practices-", "")
        public_path = f"modules/k8s-best-practices-{topic}"
        diff_text = get_diff(private_repo, commit, filepath)

        # Classify
        result = await classify_file(provider, filepath, diff_text)

        # Build file entry
        entry = {
            "id": f"f{len(files_data)+1}",
            "private_path": filepath,
            "public_path": public_path if "-vz-" not in filepath else "",
            "file_classification": "vz_specific" if "-vz-" in filepath
                else "shared",
            "file_classification_reason": result.get("reason", ""),
            "private_content_before": get_file_at(
                private_repo, f"{commit}^", filepath) if status != "A" else "",
            "private_content_after": get_file_at(
                private_repo, commit, filepath) if status != "D" else "",
            "proposed_public_content": "",
            "final_content": "",
            "decision": "auto_excluded" if "-vz-" in filepath else "pending",
            "reviewer_classification": "",
            "hunks": result if isinstance(result, list) else [result],
        }
        files_data.append(entry)

    # Build output
    data = {
        "version": 1,
        "created_at": datetime.now().isoformat(),
        "private_repo": str(private_repo),
        "public_repo": str(public_repo),
        "since_ref": commit[:7],
        "head_ref": commit[:7],
        "public_ref": args.public_commit[:7] if args.public_commit else "",
        "files": files_data,
    }

    output = args.output or f"reports/cnf-doc-sync-data-{datetime.now():%Y-%m-%d}.json"
    Path(output).write_text(json.dumps(data, indent=2))
    print(f"Classification complete: {len(files_data)} files")
    print(f"  VZ auto-skip: {sum(1 for f in files_data if '-vz-' in f['private_path'])}")
    print(f"  Pending review: {sum(1 for f in files_data if f['decision']=='pending')}")
    print(f"Output: {output}")
    print(f"\nLaunch review UI:\n  python -m cnf_doc_sync_ui --data {output}")

if __name__ == "__main__":
    p = argparse.ArgumentParser(description="CNF Doc Sync — Local Classifier")
    p.add_argument("private_commit", help="Private repo commit to analyze")
    p.add_argument("--public-commit", default="", help="Public repo commit for context")
    p.add_argument("--private-repo", default=".", help="Path to private repo")
    p.add_argument("--public-repo", default="../guide", help="Path to public repo")
    p.add_argument("--provider", choices=["ollama","openai","anthropic"],
                   default="ollama")
    p.add_argument("--model", default="qwen2.5:7b", help="LLM model name")
    p.add_argument("--ollama-url", default="http://localhost:11434")
    p.add_argument("--output", help="Output JSON path")
    asyncio.run(run(p.parse_args()))
```

### Model Recommendations

| Model | Provider | Size | RAM Needed | Speed (CPU) | Best For |
|-------|----------|------|-----------|-------------|----------|
| **qwen2.5:7b** | Ollama | 7B | 5GB | ~2.5 tok/s | Best overall for structured classification |
| **llama3.1:8b** | Ollama | 8B | 6GB | ~2 tok/s | Most robust reasoning |
| **mistral:7b** | Ollama | 7B | 4GB | ~3 tok/s | Fastest JSON extraction |
| **llama3.2:3b** | Ollama | 3B | 2GB | ~5 tok/s | Low-resource environments |
| **gpt-4o** | OpenAI | — | — | Fast | Highest accuracy (cloud) |
| **claude-sonnet-4-6** | Anthropic | — | — | Fast | Best for long documents (cloud) |

**Hardware guidance:**
- **GPU (NVIDIA/Apple Silicon):** 8GB+ VRAM — real-time (1-2s per file)
- **CPU only:** 16GB+ RAM — viable but slower (~10-30s per file)
- **Docker:** `docker run -d -p 11434:11434 --gpus all ollama/ollama`

### Three-Layer Classification Strategy

The classify.py script uses a cost-effective three-layer approach:

1. **Layer 1 — Filename pattern (instant, free):**
   Files matching `*-vz-*` are auto-classified as VZ-specific. No LLM call needed.

2. **Layer 2 — Regex scan (instant, free):**
   If ALL changed lines in a diff contain VZ markers (VCP, Doors Id, Webscale, etc.), classify as VZ-specific. Catches the common "Doors Id → Requirement Id" bulk renames.

3. **Layer 3 — LLM classification (slow, per-token cost):**
   Only triggered for files that pass Layers 1 and 2 — typically ~20% of files. The LLM classifies each hunk as generic/vz-specific/mixed with reasoning.

This means ~80% of files are classified without any LLM call, keeping costs and latency low.

## 10. PR Creation Safety Checks

The publisher (`cnf_doc_sync_ui/publisher.py`) performs before creating a PR:

1. **VZ marker regex scan:** Warns if accepted content contains VZ markers. Blocks unless the reviewer explicitly edited the content.
2. **Fragment check:** Warns if new content is < 20% of existing file size (prevents accidental partial overwrites).
3. **Clean working tree:** Refuses to proceed if the public repo has uncommitted changes.
4. **Branch naming:** Uses `sync/vz-YYYY-MM-DD` with auto-increment suffix on collision.
5. **Draft PR:** Created via `gh pr create --draft` with formatted body listing all accepted files.
